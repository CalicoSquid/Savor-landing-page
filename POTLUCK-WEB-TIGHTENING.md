# Potluck Web tightening pass

This pass deliberately removes decorative UI added in the launch-polish pass while keeping the core spin theatre, Universe voice, app funnel and Savor theme claim intact.

Changes:
- removed hero `COSMIC DINNER AUTHORITY // ONLINE` status pill
- removed the result-level `86 / VOID` teaser and its expandable upsell
- removed the standalone Void strip below the dark app section
- removed faux system labels such as `ANDROID // FREE // ...`, `APP ONLY`, and `TRANSMISSION // 03`
- removed the redundant mid-page Potluck × Savor CTA block and duplicate final Potluck download band
- simplified and tightened the Savor theme gift card
- retained the three-dot Potluck colour signature
- fixed overlay palette scoping so the third-spin prompt and desktop theme-claim modal have reliable colours
- changed the desktop theme-claim help modal to an explicitly solid cream panel over a lighter dark backdrop
- reduced visual texture/spacing in the dark app section and mobile layout

No API changes are required for this pass.
