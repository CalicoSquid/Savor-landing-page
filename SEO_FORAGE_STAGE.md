# `/forage` On-Page SEO — Staged for Review

## Discovery

The site is a React/Vite application using React Router.

- `/forage` and `/caper` both map to `src/pages/Caper.jsx` in `src/App.jsx`.
- Client-side metadata is controlled in the `useEffect` inside `src/pages/Caper.jsx`.
- Static crawler-visible metadata is generated by the `ROUTES` table in `prerender.js`.
- `netlify.toml` previously issued a permanent `301` redirect from `/forage` to `/caper`, which made route-specific metadata and an H1 impossible on `/forage` itself.

## Verified page purpose

The Caper page presents an Android wild-food companion for new and curious foragers. Its current page content offers:

- nearby wild edibles ranked by season and local findings;
- a field guide covering 893 edible species;
- safety ratings, habitats, seasons, and edible parts;
- a logbook for finds, locations, photos, and notes;
- recipes built around gathered ingredients;
- collectible badges and a one-time-payment model.
